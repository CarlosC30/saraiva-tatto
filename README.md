# 🖋️ Saraiva Tattoo

Site institucional desenvolvido para um estúdio de tatuagem, com foco em design moderno, responsividade e experiência do usuário.

## ✨ Funcionalidades

* Layout moderno com tema **Dark & Gold**
* Hero section com imagem de destaque
* Seção de serviços
* Galeria de tatuagens em CSS Grid
* Lightbox para visualização ampliada das imagens
* Fechamento do modal por:

  * Botão ✕
  * Clique fora da imagem
  * Tecla ESC
* Navegação suave entre seções
* Design responsivo para dispositivos móveis

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🎯 Objetivo

Projeto criado para praticar conceitos de:

* Estruturação semântica com HTML

* Criação de componentes interativos (Lightbox)
